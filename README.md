# Qiskit Fall Fest 2026 @ Palermo

[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](https://opensource.org/license/apache-2-0)

This repository contains the generated website for the **Qiskit Fall Fest 2026 @ Palermo**.

Visit the website at
[qiskitfallfest-palermo.github.io/2026](https://qiskitfallfest-palermo.github.io/2026/).

## Event

The Qiskit Fall Fest brought together students, researchers, and quantum computing enthusiasts to explore quantum computation, learn Qiskit, and work on projects and challenges.
